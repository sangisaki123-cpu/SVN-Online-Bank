\# SVN Online Bank



A simple console-based banking application built with Python.



\## 📌 Project Description



SVN Online Bank is a console-based banking application developed using Python.

The project allows users to create an account, log in, deposit money, withdraw

money, check their balance, and view transaction history.



Customer and transaction information is handled using CSV files.



\## 🚀 Features

|---|---|

| 👤 Sign Up | Create a new bank account |

| 🔐 Login | Login using username and PIN |

| 🆔 Account Number | Automatically generates an account number |

| 💰 Deposit | Add money to the account |

| 💸 Withdraw | Withdraw money while maintaining the minimum balance |

| 💳 Balance Enquiry | Check the current account balance |

| 📋 Transaction History | View previous deposits and withdrawals |

| 📧 Email Validation | Validates the customer's email |

| 📱 Phone Validation | Validates a 10-digit phone number |

| 🔑 Password Validation | Checks password requirements |

| 🔢 PIN Validation | Creates and validates a 4-digit PIN |

| 🏦 Account Type | Choose Savings, Current, or Salary account |



\---## 🛠️ Technologies Used



\- Python

\- CSV

\- Regular Expressions

\- File Handling
